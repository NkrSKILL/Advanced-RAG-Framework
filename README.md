# Advanced-RAG-Framework

🚀 **Production-ready Advanced Retrieval-Augmented Generation Framework** built with Python.

## ✨ Features

- **Advanced Query Processing**: Query rewriting, decomposition, HyDE, RAG-Fusion
- **Hybrid Search**: Vector + Keyword + Semantic
- **Post-Retrieval**: Reranking, Compression, Relevance Filtering
- **Multi-Vector & Parent-Document Retrieval**
- **Evaluation Suite**: RAGAS, ARES, custom metrics
- **Multiple Vector Stores**: Chroma, FAISS, Pinecone, Weaviate
- **Document Loaders**: PDF, Markdown, Web, YouTube, etc.
- **Agentic RAG & Routing**

## 🛠️ Quick Start

```bash
pip install -r requirements.txt
```
